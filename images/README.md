# Images Folder

Place your images in this folder and reference them in the HTML files.

## Recommended images

| Filename         | Size        | Usage                                  |
|------------------|-------------|----------------------------------------|
| `profile.jpg`    | ~400×500px  | Photo of the occupational therapist    |
| `hero.jpg`       | ~1400×800px | Optional hero background image         |
| `og-image.jpg`   | 1200×630px  | Social media / Open Graph preview image|

## Tips

- Use `.webp` format for better performance (convert with Squoosh or similar)
- Compress images to under 200 KB where possible
- Always include descriptive `alt` text in the HTML when adding images
- See `SETUP.md` section 5 for instructions on adding images to the site
